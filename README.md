# SafeLight.Dev game saves

A collection of Xbox 360 game saves gathered over the last twenty years from community members and from sites that no longer exist. Each set has been vetted, tested and documented again with clear steps, so it is easier to follow than the original posts.

## Credit

Where the original author left a README, or the author was known, their credit is kept with the set. Where it was not, the set is uncredited.

## What is in a set

Each set is a GitHub Release with one zip attached. Sets differ in what they do and how many saves they hold, so each release page says what the saves contain.
