# SafeLight.Dev game saves

Load-and-pop save sets for Xbox 360 games. Load the save in the game and the achievements it covers pop on their own. No playing needed.

Each set is a GitHub Release with one zip attached. The zip has its own README with the full steps.

| Tengai Makyou Ziria: Haruka naru Jipang | NTSC-J, Title ID 485507D2 | 1,000 G, 50 achievements | [Release](https://github.com/SafeLightDev/game-saves/releases/tag/485507D2-ziria-r1) |

## How to use a set

1. Use a throwaway profile first, not your main one.
2. Resign the save to your profile with a save resigner.
3. Copy it to `Content\<your profile ID>\<Title ID>\00000001\` on the console.
4. Load it in the game and wait for the achievements to pop.

Sets with a Legit Order folder are loaded one save at a time, in order. Sets with a Load Pop 1K folder pop everything in one go.

These saves are for consoles that can load resigned saves. Back up your own saves first.
